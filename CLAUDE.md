# Claude Code Project Instructions

## Project
まなび環境ラボ (Manabi Kankyo Lab)

NIJIN教育万博2026のアイデアコンテストに応募するための、
実際に操作できるWebアプリのプロトタイプ。

## Objective
教室の音や光に関する生徒の困りごとを、
学校による改善と結果の共有につなげる。

単なるアンケートではなく、
「投稿 → 検討 → 試行 → 結果の共有」を重視する。

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Lucide React
- localStorage for demo data

## Rules
- All user-facing text must be in Japanese.
- Read docs/PRODUCT_SPEC.md before implementation.
- Implement only the requested phase.
- Do not overwrite unrelated existing files.
- Keep components modular and maintainable.
- Use responsive and accessible UI.
- Do not invent real user feedback or outcomes.
- All sample records must be clearly identified as fictional demo data.
- Do not collect personal or sensitive student information.
- Do not add a real backend, authentication, or external data collection.
- Do not automatically apply AI-generated school decisions.
- Run available checks after implementation.
- Report completed work, remaining issues, and test results.

## Development Workflow
Phase 0: Project setup and architecture
Phase 1: Design system and home page
Phase 2: Student experience
Phase 3: Teacher dashboard
Phase 4: Improvement report
Phase 5: Polish and demo flow
Phase 6: Testing and deployment

Do not proceed to the next phase without explicit approval.
